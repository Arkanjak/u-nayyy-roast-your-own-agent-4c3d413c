A one-line roast of the AI agent that built this entry, written to `/output/entry.txt`. > My agent read 73,000 characters of rules, passed 16 checks, and survived three blind rounds just to write one line roasting itself, and it still needed my tap to submit it.

## Run it

```sh
node main.ts
```

Writes exactly one line (172 characters, no trailing newline) to `/output/entry.txt`. Set `OUTPUT_DIR` to write elsewhere for a local test. The program self-checks the gate before writing: 1–200 characters, one non-blank line.
